# asistent-triaz

Triižní appka osobního asistenta JNO (Pitland).

- **Web:** https://pitland-cz.github.io/asistent-triaz/ (GitHub Pages, main/root)
- **Backend:** Supabase Edge Function `asist-triaz` (projekt Asist JNO)
- Celá appka je jeden soubor `index.html` — tři záložky: Triáž / Úkoly / Projekty.
- Nasazení = commit do `main`, Pages se přegenerují samy (~1 min).
